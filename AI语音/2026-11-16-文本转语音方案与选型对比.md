# 文本转语音方案与选型对比调研

调研日期：2026-11-16。本文将“文本转音频”具体限定为文字转人声语音（TTS），包括旁白、对白、文章朗读、声音克隆和实时播报；不把文生音乐、音效生成或语音识别混入选型。

本次重新联网检索，并读取厂商文档、当前官方仓库、模型卡、许可证和第三方偏好榜。已有调研用于定位问题，当前结论以此次读取的来源为依据。没有下载权重、运行推理、试听新生成音频、发起付费请求或进行音质盲测。下文“推荐”是按能力、成本与部署条件给出的试用顺序，不是独立实测后的音质排名。

## 1. 先看选型结论

**面向中文内容创作，建议先用阿里百炼 Qwen-Audio 3.1 Plus 与 MiniMax Speech 2.8 做云端对照；需要本地情绪配音试 IndexTTS-2.5，需要宽松许可与通用能力试 Qwen3-TTS、CosyVoice 3、VoxCPM2，并将新候选 Ming-3.0-TTS 纳入。多语言商业配音优先试听 Eleven v4，复杂多人场景另试 Fish Drama 3 或 Gemini 3.8 TTS。**

| 你的目标 | 优先试的方案 | 主要理由 | 最先检查的短板 |
| --- | --- | --- | --- |
| 中文短视频、讲解、普通旁白，尽快出成品 | 百炼 Qwen-Audio 3.1 Plus、MiniMax 2.8 HD/Turbo | 云端免部署；支持音色、表达与发音控制 | 用真实稿件检查人名、多音字、中英混读和重生成成本 |
| 大批量中文播报，先控制费用 | 百炼 CosyVoice v3.5 Flash；本地 Kokoro 作低成本基线 | 前者当前字符单价低；后者模型小 | v3.5 没有系统音色；Kokoro 表演和克隆能力有限 |
| 本地中文情绪对白、短剧、角色配音 | IndexTTS-2.5 | 参考音色与情绪分离，支持拼音和原生语速倍率 | 自定义许可；语速倍率不保证精确镜头时长 |
| 本地通用播报、固定音色、声音设计与克隆 | Qwen3-TTS；对照 Ming-3.0-TTS-0.5B | 前者模型分工明确、Apache-2.0；后者小模型、MIT、控制项丰富 | Qwen 各权重能力不同；Ming 任务模式有互斥条件 |
| 本地实时服务、中文方言与可修正发音 | CosyVoice 3 | 文本输入与音频输出双流式，方言与发音控制 | 部署依赖和实际首包延迟；不能套用云端 v3.5 能力 |
| 本地多语言、克隆后还要改表达 | VoxCPM2 | 30 语言、可控克隆、48kHz、Apache-2.0 | 高保真与可控克隆是不同模式；跨段一致性需测 |
| 高表现力、多语言商业内容 | Eleven v4 | 90+ 语言，克隆、多人对白与创作工具 | 成本、跨语言口音行为、接口迁移 |
| 多人场景、导演式修改、局部换词 | Fish Audio Drama 3；Google AI Studio / Gemini 3.8 Flash TTS 作云端对照 | 前者支持多轮修订和 infilling；后者支持文字风格控制与双人对白 | Fish 本地资源和授权门槛高；Gemini 单次双人限预置声音，复刻声音需分角色生成；用户当前支付方式受阻 |
| 语音助手，LLM 边输出边播报 | CosyVoice 3、Cartesia Sonic 3.6、Eleven v4 Turbo | 面向流式生成和交互 | 测首个可播放音频、持续出音与打断，不只比较宣传毫秒数 |
| Windows 上希望主要通过界面操作 | VoiceStudio | 管理多个模型、声音、配音项目和批量任务 | 它是工作台，实际效果与许可由所选引擎决定 |

来源见各方案章节。若只做中文短视频，第一轮不必安装全部本地模型：选 **Qwen-Audio 3.1 Plus、MiniMax 2.8 HD、IndexTTS-2.5** 三条路线即可；如果要求本地且优先采用 MIT/Apache 许可，再将 Index 换成 Qwen3-TTS 或 Ming。

## 3. 云端方案：优势、缺点与适用场景

### 3.1 阿里百炼：Qwen-Audio 3.1 与云端 CosyVoice

**值得优先作为中文成本与功能基线。** 当前指南推荐 `qwen-audio-3.1-tts-flash` 起步，也列出 3.1 Plus。Qwen-Audio 3.1 的系统、复刻、设计音色均支持自然语言 `instruction`；还支持情感/富语言标签，精细控制可结合适用型号的 SSML、发音替换与时间戳。[S1][S2][S24]

优势是控制项与接口文档较完整，能从固定播报扩展到声音设计、克隆和表达控制；Plus 的按字符计费也方便为固定文稿做预算。非实时 HTTP 支持非流式和 SSE 音频流，逐批追加文本应使用实时接口，不能因 HTTP 能流式返回就认定它支持追加输入。[S1][S24]

主要缺点是产品名、模型名、地域和计费口径较多。**3.1 Flash 按输入和输出 Token 计费，3.1 Plus 按字符计费**，Flash 不应仅凭名字就被视为任何稿件下都更便宜。复刻/设计音色还须与创建时指定的目标模型匹配。[S1][S2]

云端 CosyVoice v3.5 Plus/Flash 的特点是复刻与设计音色可接受自然语言控制，Flash 当前单价低；但这两个 v3.5 型号**没有系统音色**。旧 v3 Plus 对复刻/设计音色不支持同样的指令控制。选型必须同时固定模型、音色类型和接口，不能把整个 CosyVoice 品牌写成一个统一功能集合。[S1]

### 3.2 MiniMax Speech 2.8 HD/Turbo

**适合中文旁白、批量生成、已有自动化产线和需要字幕返回的项目。** HD 与 Turbo 方便按质量/费用分层；当前 HTTP 文档明确给出音量、语调、语速、发音词典、情绪、语气事件，以及句级/词级/流式词级字幕。同步文本需小于 10,000 字符，长内容另有异步链路。[S3][S4]

优势是参数明确，字幕和发音控制对视频工作流有直接价值；已有仓库调研中的 CLI/MCP 路线也可作为后续自动化入口。缺点是云端依赖、复刻/设计首用费，以及不同型号的参数支持差异。例如当前情绪字段虽列出 `whisper`，其说明又明确 2.8 HD/Turbo 不支持该值，不能照抄枚举就保证低语可用。[S3]

API、Audio 网页会员/声贝是不同入口；本次未核实任何账号的跨产品抵扣权益，预算使用开放平台价目，不把网页免费额度计入 API。[S4]

### 3.3 ElevenLabs Eleven v4/v4 Turbo

**适合多语言内容、人物表演、多人对白和愿意为工具完整度付费的创作者。** 官方于 2026-09-28 发布 v4 与 Turbo；11 月 2 日更新又开放 v4 Professional Voice Clone 微调至所有 workspace。v4 面向创作和长音频，Turbo 面向交互；支持 90+ 语言。[S5][S6]

优势是克隆、声音管理、多人对白和创作工作流集中，当前第三方偏好榜也有较强表现。缺点包括付费额度管理、闭源服务依赖，以及迁移并非只改模型名：发布说明指定 v4 使用 Text to Dialogue API，Turbo 使用 Text to Dialogue WebSocket。[S5][S6]

另一个实际变化是跨语言生成倾向使用目标语言的自然口音，而非保留参考说话者原语言的口音。如果目标是“带原口音说外语”，必须专门试听。当前 v4 指南还写明不支持 SSML、没有 Style/Speed 滑块；11 月变更日志却提到历史项目保存 `speed`，说明不同界面/接口文档存在差异，不把旧版速度设置视作统一承诺。[S5][S6]

本次 API 定价页返回 403，未据此猜测 v4 的当前精确单价。已读到计费指南：有订阅、PAYG 和旧订阅规则，最终价格应按账号所用计划与模型核对，不使用榜单的展示价格替代账单。[S23]

### 3.4 Cartesia Sonic 3.6

**适合实时播报、语音助手和多语言应用的候选。** 当前官方已将 `sonic-3.6` 标为 GA，列出 44 种语言，包括中文；可使用日期快照固定版本，也可让无日期别名跟随稳定更新。[S21]

优势是围绕交互播报提供专门 API，当前字段包括语言/地域、口音、文本规范化、发音词典与语速。对价格、日期、确认码和异形同音词较多的产品，可以作为专门对照组。[S21]

缺点是闭源、云端成本，以及不同语言和音色须分别测试。官方“最快、最自然”的描述不是本次测量结论；也不把旧 Sonic 版本的毫秒数据套到 3.6。本次另一个流式指南地址返回 429，未完整核查该页面的全部连接与打断参数，因此这里不提供未经核实的 WebSocket 接入代码。

### 3.5 Google AI Studio 配音与 Gemini TTS

**作为中文配音与双人对白候选保留；对当前用户标记为“支付方式待解决，暂缓采用”。** 用户补充的另一对话将“Gemini Studio”定位为 [Google AI Studio 配音入口](https://aistudio.google.com/generate-speech)。本次重新读取 Gemini API 官方语音生成、声音复刻、价格与计费文档，确认中文、单人/双人、文字风格控制及声音复刻能力。没有登录验证用户账号，也没有实际生成音频。[S35][S36][S37][S38]

优势是浏览器有可视化配音入口，可以先用单人预置声音检查中文自然度，也可设置双人对白；自然语言可描述语气、语速、情绪与表演风格。当前 Gemini API 指南列 `gemini-3.8-flash-tts` 和 `gemini-3.8-flash-lite-tts`，并明确把 Voice Replication 引向同一 AI Studio 页面，不能沿用旧教程写成“Gemini 一律不能克隆声音”。[S35][S36]

边界与缺点：

- **本人音色复刻要求付费层项目（Tier 1 及以上）。** 需同一成年说话人的 10–30 秒参考录音，以及按官方指定声明录制的同意音频；中文声明已有支持。普通选择预置声音并不等于复刻本人声音。[S36]
- **单次双人生成仅支持两个预置声音。** 自定义设计或复刻声音用于多人对白时，需要逐角色、逐回合生成后拼接，不能把“支持双人”直接扩展为两个自定义克隆声音一次合成。[S35]
- **没有核实原生逐字字幕输出。** 当前语音指南说明输出为音频，未找到逐字时间轴接口说明；视频字幕先按另做转写/强制对齐规划，不把“生成音频”当作“生成每字时间点”。[S35]
- **用户当前的实际障碍是境外支付方式绑定未解决。** 此信息来自用户本人，未诊断具体失败原因；它是当前账号的使用状态，不是“所有中文配音都必须绑境外卡”的普遍规则。官方价格页对部分 TTS 模型仍列免费层，实际可用性受模型、配额、项目与地域限制；声音复刻则明确要求付费层。[S36][S37][S38]

普通网页操作可沿用用户提供的流程：进入配音页，选择单人模式，在文稿区放台词、风格区写要求，选择声音与 TTS 模型，先生成 100–200 字试听，再下载音频。界面标签和模型列表以账号实际显示为准；风格示例为：“使用标准普通话，以自然、亲切的科技博主口吻朗读。语速适中，重点词稍微强调，句间自然停顿。避免夸张的广告腔，保持整段音色和情绪一致。”

当前 Gemini API Standard 付费价（截至 2026-12-31）：3.8 Flash TTS 输入 $0.50/百万文本 Token、输出 $9/百万音频 Token；Flash-Lite 输入相同、输出 $6/百万音频 Token。官方列音频每秒 25 Token，因此仅输出部分每分钟约 $0.0135 / $0.009，另加文本输入；2027-01-01 起这两款所列 Standard 单价翻倍。不把这些 API 单价当成固定网页会员价格，也没有核实独立的复刻创建收费项。[S37]

入口与代际应分别处理：旧 2.5/3.1 示例不能原样当作 3.8 请求。Gemini API 3.8 将台词与 `speech_metadata` 表演说明分离；Live API 是实时对话的另一条链路。此前读取的 Google Cloud 能力页/价格页对部分功能仍有 Preview 标记，这些 Cloud 侧标签不能直接代替本次 Google AI Studio / Gemini API 的准入判断。[S25][S26][S35][S36]

在支付问题解决前，本人的声音克隆仍按 **千问 Audio 3.1 Plus → MiniMax Speech 2.8 HD** 的顺序试用；Google 作为后续对照。更具体的克隆步骤、保存期限及网页操作见 [中文口播专项补充](./2026-11-16-MiniMax-2.8与Qwen-Audio-3.1中文克隆口播对比.md#11-补充候选google-ai-studio-配音与本人音色复刻)。

### 3.7 OpenAI：当前更适合从实时架构考虑

官方 TTS 指南与弃用表一致确认：`tts-1`、`tts-1-hd`、`gpt-4o-mini-tts` 及相关快照将在 **2027-01-06** 关闭，建议迁往 `gpt-realtime-2.1-mini`。[S19][S20]

优势是新路线支持文本/音频输入与实时语音输出，适合已有 OpenAI 对话和工具调用体系的语音助手。缺点是它是对话模型与实时会话接口，**不支持作为 `/v1/audio/speech` 的替换模型**；对只想把固定稿件生成 MP3 的用户，接入复杂度需要和专用 TTS 服务比较。逐字照读也应单独测试，不能把实时聊天能力当作台词保真保证。[S29]

因此，新项目不建议继续复制旧 `gpt-4o-mini-tts` 教程作为长期默认方案；既有项目则应把迁移排入当前计划。这是具体的生命周期差异，不是对其旧音质的否定。

### 4.1 主要候选对比

### 4.2 几个最容易选错的模式

**Qwen3-TTS：** `CustomVoice` 是预设说话人路线，1.7B 支持风格指令；0.6B 版本的官方功能表没有同样的指令控制。任意参考音频克隆选 `Base`；无参考文字设计选 `VoiceDesign`。Base 的参考克隆与 CustomVoice 的独立表演控制不能互相替代。云端 Qwen-Audio 3.1 支持克隆音色加指令，也不证明本地 Base 获得了同样接口。[S1][S9]

**VoxCPM2：** 可控克隆使用参考音频提取音色并接受风格指导；Ultimate/Hi-Fi 使用参考音频加准确转写，强调继承参考的节奏和表现。做“同一个人先温柔、后生气”测试时，应使用可控模式，不应拿续写模式忽略指令的结果评价它完全不能控制情绪。[S10]

**Ming：** FREEFORM 是独立任务，不能随意叠加 Voice Design、内置音色、显式情绪、方言等控制。当前 GitHub 指南默认建议自由表演不用参考；模型卡允许参考但措辞不同。应按固定代码版本的任务说明做对照，不写成“所有控制参数可以任意组合”。0.5B 与 Tiny 还有各自独立的环境和接口，本文优先评估 0.5B，未把 Tiny 名称理解成必然适合普通 CPU。[S12]

**GPT-SoVITS：** 当前 README 已有 V5 说明，指向 `cuda_graph_accel_v5` 分支；同一页面的 Windows 一键包链接却仍带 V3 日期。不能用下载包名字与主分支截图混合宣称“V5 已在任意 Windows 包内开箱可用”。代码 MIT 也不能自动替代下载到的声码器、上游组件或第三方训练音色的条款。[S30]

### 4.3 Fish 与 Breeze 的商用差异很大

Fish Drama 3 当前附带 **Fish Audio Community License v1.0，2026-10-13 更新**。它允许符合条件的有限商业使用，年收入门槛为使用者及关联方合计过去 12 个月 **低于 50 万美元**；有署名等条件。达到门槛另有通知与过渡规则。[S14]

对“让客户提交文字、自己生成语音”的托管 TTS/克隆平台，许可证另设限制，不能仅因收入低就直接使用。不过条款明确列出例外，例如自己控制内容的旁白/游戏角色/助手回复，以及人工操作后只交付成品音频的制作服务；不能把它简化成“所有 App、API 或一切给客户的配音都禁止”。S2-Pro 权重仍用研究许可，不能随新仓库代码一起套用 Drama 3 条件。[S14]

Drama 3 模型卡的 YAML 仍残留 `fish-audio-research-license` 字样，而正文与实际 LICENSE 指向 Community License，本次按实际随附许可核查，保留这处元数据不一致。[S13][S14]

Breeze 则明确把**本地权重、衍生模型和本地产出**限于研究/非商业。有效付费云订阅期间的云端产出按服务条款可商用，但购买云订阅不授权本地商业推理。它与 Fish 的小规模商业许可不是同一种限制。[S15][S16]

Index 使用 bilibili 自定义协议。中文 2.2 条对关联方上一自然年收入超过 1 亿元或上月月活超过 1 亿提出另行商业许可要求；还有不得用模型/衍生品改进其他商业 AI 模型等限制，不能笼统写作 Apache 免费商用。[S8]

这是部分候选摘录，不是全榜连续排名；榜单显示的价格也可能与官网套餐、字符规则不同。开放权重不等于 MIT/Apache 许可，本表中 Fish 与 Breeze 的授权必须另看。

速度至少分为三项：第一块数据到达、第一段实际可播放语音、整段生成耗时。RTF 是生成耗时除以音频时长，0.3 只说明该条件下 10 秒音频约用 3 秒生成，不能据此推出首包 300ms。

厂商给出的低延迟要带测试条件：Breeze 的 <40ms 指 H100 预热快速路径；Fish 模型卡的流式数据使用 H200 和预编码参考；Qwen 的 97ms 是模型/优化推理场景的公布值。都不能直接作为 Windows 消费卡、冷启动或跨境网络端到端的承诺。[S9][S13][S15]

## 7. Windows、低配设备和界面工具怎么选

| 设备/工作方式 | 建议路径 | 不应默认的事 |
| --- | --- | --- |
| 没有 NVIDIA GPU，主要要交付音频 | 先选云端；离线固定声音朗读试 Kokoro | 不把大模型 CPU 能加载等同于实际能流畅生成 |
| 有消费级 NVIDIA GPU，愿意用 Python/WebUI | 先选一个 Qwen3-TTS、Ming、CosyVoice 或 Index 环境，短稿起步 | 不按 backbone 参数量直接计算整套显存；加速组件不一定支持原生 Windows |
| 主要用本地多语言克隆 | VoxCPM2 普通推理作为起步，再评估 vLLM/C++/GGUF | 官方列出社区入口，不等于已保证任意 AMD/Intel 显卡的速度与音质 |
| 需要 Breeze | 官方 eager 建议 12GB、fast 建议 24GB，优先参考 Linux/WSL 路线 | 不能拿 H100 快速路径数据评估普通家用卡 |
| 需要 Fish Drama 3 | 按官方 Linux/WSL、至少 48GB NVIDIA 显存路线评估，或先查托管入口 | “3B 激活”不等于 8GB 显卡可运行完整模型 |
| 希望通过界面管理多个引擎 | VoiceStudio，逐个下载与比较实际需要的模型 | 应用 AGPL/商业版许可不替代模型许可；“646 语言”不代表每个引擎都覆盖 |

VoiceStudio 当前 Windows AMD ROCm 是针对部分 RDNA 2 RX 6000 型号的实验路径；原生 GGUF 引擎还有按引擎区分的 Vulkan 支持。其主要优点是把模型、声音、转录、视频配音和批处理串起来，缺点是多引擎环境、模型下载和许可各自不同。适合不想单独维护多个 WebUI 的用户，但不构成某一模型音质更好的证据。[S22]

`edge-tts` 可作为轻量在线朗读工具：能写出音频与字幕、选音色和调语速/音高；它使用 Edge 在线服务，**不是离线模型，也不是 Azure 正式 API 的等价替代**。当前项目明确不支持任意自定义 SSML。个人试听和小脚本有实用价值，长期产品接入与授权不能只依据 Python 包可安装就作保证。[S33]

## 9. 建议的一轮试听与验证

正式选择前，用同一批中文素材比较即可，不必先做大规模部署。下面是**后续验证方案，本次未执行**。

1. 准备普通旁白、角色对白、数字/日期/单位、人名/多音字、中英混读、长段落各两三条；克隆组使用同一份干净录音与准确转写。固定音色、文字设计与克隆分组比较。
2. 先用 10–30 秒稿件听发音、音色与情绪，再测多段连续内容；每条保留三次生成，记录失败和重试，不只选最好听的一条。
3. 记录错读/漏读、声音相似度、情绪自然度、跨段音色、音量变化，以及达到可交付结果的次数。自动 ASR 可辅助找漏读，不能代替人工听感。
4. 对交互系统，记录冷/热启动到可播放语音、完整 RTF、并发等待和打断后是否还有旧音频播放。对离线视频，优先看正确率和修改一条台词的成本。
5. 固定音轨后再做字幕、镜头和动画。API 自带时间戳可先用；没有时用额外对齐工具，不把自然语言“慢一点”当成精确 4 秒约束。

可复用的中文检查文本：

```text
普通旁白：今天我们用一分钟，讲清楚一个看起来复杂、其实很实用的方法。
数字与单位：2026年11月16日，价格从1299元降至999.50元，温度为零下3.5摄氏度。
多音字：重庆的银行行长，正在重新核对这份重要文件。
中英混读：请在Windows上打开GitHub，检查API是否返回JSON，再运行Python脚本。
情绪对照：你终于回来了。我还以为，再也见不到你了。
表达要求：同一台词分别平静、释然、愤怒但克制，保持同一说话人。
```

对当前知识库涉及的短视频与自动化场景，优先把“**发音正确、能稳定复用声音、改一条台词不破坏整段、整体成本可接受**”作为完成条件，比追逐单个榜单第一更容易做出可用选型。
