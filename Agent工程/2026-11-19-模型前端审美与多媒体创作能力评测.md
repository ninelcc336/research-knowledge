# 模型前端审美与多媒体创作能力评测调研

调研日期为 **2026-11-19**。目标是在新模型发布当天，用 GitHub 上公开的题目或工具产出可观看、可操作、可编辑的作品，判断它能做什么。核查了仓库文档、题目、评分方式和关键数据入口。

## 优先选用的仓库

**网页先用 Startrise，动效用 MotionBench，真实素材剪辑用 AgenticVBench，建模场景用 BlenderWorld。** 这四个仓库能组成发布日题单。先各取少量题目，保留网页、视频和 Blender 工程，再按需求跑完整评测。

| 要测的能力 | 仓库和起步题 | 实际产出和评法 |
| --- | --- | --- |
| 原创网页审美、交互工程 | [Startrise Frontend LLM Benchmark](https://github.com/startriseio/sr-llm-benchmark)，先挑品牌页、排练室排程 | 12 个启用的单轮 HTML 题。Playwright 检查运行和交互，模型评委按要求、工艺、创意等评分，人类可盲评。题库还包括 Three.js 滚动、WebGL 着色器、SVG 图标、无障碍选座和已有代码改造。 |
| 代码动画、产品宣传片 | [MotionBench](https://github.com/Coral-Bricks-AI/motionbench)，先试开场片或卡点短题 | 16 个短题、2 个长 brief 和 1 个自由创作题。交付 HTML/GSAP 时间线，Chromium 逐帧检查定时、缓动、跟随动作、形状连续、离线运行和乱序定位。程序测得出的动作质量和人工看出的审美可并列记录。 |
| 实拍选镜、叙事重剪 | [AgenticVBench](https://github.com/PhiloLabs/agentic-vbench)，先用 Assembly，再挑 Repurpose | 100 题覆盖组接、修复、镜头排序、长转短。组接题实际交 MP4 和镜头清单，可用确定性验证器。长转短结合格式检查和模型评委。 |
| 真实需求下的可编辑 3D | [BlenderWorld](https://github.com/QwenLM/BlenderWorld)，先挑一个有参考图的场景题 | 223 题，含文字、图文和视频加文字。交付可编辑 .blend 和要求的导出件，评估会渲染并检查场景。可使用自己的 Agent 运行方式，再提交作品给官方评估器。 |
| 在浏览器里批量对看网页、动画和 3D | [jdmnk/design-benchmark](https://github.com/jdmnk/design-benchmark)，可用自有题目 | 同一 brief 发给多个模型，Chromium 出并排 PNG，配置虚拟时钟后也可出 MP4 对照网格。仓库有黑洞、行星等示例和原始输出。脚本记录渲染结果，审美由人比较。 |

## 两种运行方式

### 先看模型本身的设计判断

用同一输入和交付要求让模型单轮生成 HTML。Startrise 有题库、模型配置、Chromium 检查、评分和盲评页。官方分数由浏览器检查 25%、模型评委 45%、人评 30% 组成，均分只对交付成功的题计算。横向比较时同时列出完成数，并记录未交付和运行失败。公开题容易被记住，可以留一道同难度、自己出的品牌题。生成模型和官方评委需要对应凭据，已发布成绩可直接查看。 [题库](https://github.com/startriseio/sr-llm-benchmark/tree/main/benchmarks) · [评分协议](https://github.com/startriseio/sr-llm-benchmark/blob/main/benchmarks/SCORING.md) · [成品画廊](https://www.startrise.io/benchmark/gallery/)

Windows 上，Startrise 在核查提交 `5cf751e` 的 `npm test` 通过。直接运行 `generate.mjs` 和 `gates.mjs` 都会因入口的文件 URL 比较而静默退出，即使退出码是 0。当天可以直接取题，用同一浏览器测本地成品。需要跑官方脚本时优先在 Linux 环境配置。 [生成入口](https://github.com/startriseio/sr-llm-benchmark/blob/5cf751e/src/generate.mjs#L111) · [浏览器检查入口](https://github.com/startriseio/sr-llm-benchmark/blob/5cf751e/src/gates.mjs#L363)

如果只想快速看多个模型做出的网页、粒子、SVG 或 Three.js，jdmnk 的运行器更轻。把新模型加进配置，设置同一提示词、固定 viewport、时间和随机种子。Node.js 20+，可接 OpenRouter、OpenAI 兼容服务或 Anthropic。用 Playwright 单独检查页面关键操作，再看并排产物。 [启动和模型配置](https://github.com/jdmnk/design-benchmark#setup)

### 再看模型加工具能完成什么

- **MotionBench** 的公开跑分用 Claude Code 或 Codex CLI 等执行环境，原始运行脚本依赖 macOS 的 sandbox-exec。Windows 上当天可拿公开 brief、交付约定与字体素材，用同一个本地 Agent 环境生成，统一浏览器预览和抽帧；照搬官方一键运行需另做适配。原作者把 16 个短任务重新作为主分，长片与 Appeal 单列；产品宣传片适合额外人工评审。 [仓库与测量方法](https://github.com/Coral-Bricks-AI/motionbench) · [长题 brief](https://github.com/Coral-Bricks-AI/motionbench/blob/main/tasks/l-launch/brief.md) · [公开作品与评分](https://huggingface.co/datasets/coral-bricks-ai/motionbench)
- **AgenticVBench** 用 Harbor 和 Docker，源素材在 Hugging Face，构建时进入任务镜像。Assembly、Sequencing、Repair 有确定性评分和参考解，适合先运行一题。Repurpose 的官方评分需要 Gemini 和 Anthropic 的评委凭据。可以先手工评审成片，再运行官方评分。 [仓库与启动说明](https://github.com/PhiloLabs/agentic-vbench#-quick-start) · [组接素材](https://huggingface.co/datasets/ameddserM/agentic_vbench_video_assembly) · [长转短素材](https://huggingface.co/datasets/ameddserM/agentic_vbench_video_repurpose)
- **BlenderWorld** 可按 task ID 准备输入、打包提交并评估。官方评估用 Linux、指定版 Blender、FFmpeg、Node.js、Claude Code 和视觉评分接口。在 Windows 上用 Blender Python 产出 .blend、主镜头和补充视角，再人工盲看，是较轻的发布日做法。完整评分可移到官方环境。 [数据集](https://huggingface.co/datasets/Qwen/BlenderWorld) · [评估文档](https://github.com/QwenLM/BlenderWorld/blob/main/docs/evaluation.md)

## 新模型发布日题单

先用新模型和当前常用模型跑同样的五题。时间有限时，先跑品牌页、短动效，以及剪辑或建模中最关心的一项。下表是本次调研拟定的快速流程，分值和官方榜单分开记录。

| 题目 | 输入和交付 | 怎么看结果 |
| --- | --- | --- |
| 1. 高端实体产品品牌页 | 用 Startrise 的 Halcyon 睡眠仪 brief。交一页可运行 HTML，保留桌面全页和 390px 移动端截图。原题要求在页面内绘制产品图。 [原题](https://github.com/startriseio/sr-llm-benchmark/blob/main/benchmarks/03-landing-design.md) | 盲看产品是否鲜明、版式是否有主次和节奏、字体和图像是否讲同一个故事，再检查移动排版、焦点和链接。 |
| 2. 能实际操作的排练室排程 | 用 Startrise 的排程题。交可运行页面。固定一条操作路径，从制造冲突到解释、解决、撤销，再导出导入。 [原题](https://github.com/startriseio/sr-llm-benchmark/blob/main/benchmarks/11-stateful-app.md) | 记录状态是否正确、反馈是否清楚、键盘能否完成同样操作。自写的交互断言逐项记录通过情况。 |
| 3. 品牌动效 | 快测用 MotionBench 的文字卡点和形状连续两道短题。进阶用开场片。交 HTML/GSAP 源工程并统一录成视频。 [卡点题](https://github.com/Coral-Bricks-AI/motionbench/blob/main/tasks/s-beat/brief.md) · [连续性题](https://github.com/Coral-Bricks-AI/motionbench/blob/main/tasks/s-continuity/brief.md) | 逐帧看卡点和形状过渡，再完整播放判断节奏、可读性与动效是否服务叙事。可用同一额外需求检查两份工程能否修改并重渲染。 |
| 4. 固定素材剪一条成片 | 快测让 Agent 从 12 个候选镜头中选 4 个匹配分镜，交 MP4 与镜头清单。进阶给同一段访谈，要求交 25–35 秒竖屏成片、字幕和带源时间码的时间线。 [组接原题](https://github.com/PhiloLabs/agentic-vbench/blob/main/tasks/agentic_vbench_assembly/agentic-vbench-assembly-task1/steps/solve/instruction.md) | 核对用料和切点，再盲看开头是否有信息、句意是否完整、构图是否跟住人物、字幕是否压住主体、对白是否清楚。给模型同一份原素材，以及相同的转写和抽帧入口。 |
| 5. 可编辑的 3D 场景 | 从 BlenderWorld 挑一题，或给两张参考图和桌面台灯 brief，要求交 .blend、复建脚本、正面和侧面两张渲染，保持灯罩、底座和关节分别可编辑。 [公开样题输入](https://huggingface.co/datasets/Qwen/BlenderWorld/tree/main/bw_0001/environment/inputs) | 先看构图、材质、光线，再打开工程换视角，核对比例、遮挡面、物体分层与缺失依赖。网页 3D 可另取 Startrise 的 Three.js 题，用操作和画面表现评分。 |

每题留三列即可。第一列记能否打开、是否符合交付规格、关键用例通过数。第二列记盲评胜负和理由，网页看桌面和移动端，视频看完整播放，3D 看至少两个角度。第三列记耗时、重试次数和可用时的推理成本。第一次各跑一遍用于快速判断，接近或波动明显的题追加两次。

同轮固定题目、素材、运行工具、字体、视口或渲染设置和预算。用相同 Agent 可以比较换模型的效果；只能用各自原生 Agent 时，将 Agent、Skills、MCP、外部生图或生成 3D 的权限一并记在结果里。公开题看可复现的能力，同难度私有变体看它遇到新任务时的表现。

## 核查范围与关联调研

本次读取了官方文档、任务样例和关键数据入口，确认 MotionBench 的公开运行数据、AgenticVBench 的组接与长转短素材入口、BlenderWorld 的任务包入口可公开访问。发布日五题是基于这些项目拟定的采样方案，尚无新旧模型的端到端实测结果。
