# 国内静态网站托管与视频播放方案调研

调研日期：2026-10-17。面向需求：公开分享文档和视频，视频在网页内播放，主要读者在中国大陆。

## 结论

**静态网站完全可以展示文档并播放视频，不需要因为有视频就购买服务器。** 网站可以只包含 HTML、CSS、JavaScript；视频由浏览器向对象存储、云点播或视频平台请求并播放。

**新项目不建议依赖 Gitee Pages。** 本次没有核实到其当前可新开通、可持续发布的官方依据；旧教程不能证明服务仍可用。Gitee 可以继续保存 Markdown 和网站源码，网站发布到其他服务。

**以大陆用户的访问体验为优先，推荐“静态站点生成器 + 国内 COS/OSS + 自有域名 + HTTPS”，按访问量增加 CDN。** 少量视频直接放对象存储；需要自动转码、多清晰度、播放鉴权时再接云点播。代码仓库放在 GitHub 还是 Gitee，不决定访客访问网站的速度。

如果希望免备案、低门槛先试做，可用海外静态托管或香港等境外服务器，但跨境访问质量需要实测。没有找到可以同时保证“永久免费、免备案、大陆稳定访问、大量视频随意播放”的方案。

## Gitee Pages 到底能不能用

需要区分代码托管与网页托管：Gitee 仓库能够存文件，不代表仓库中的 HTML 会作为独立网站发布。

本次证据及其边界如下：

| 核查项 | 结果 | 能说明什么 |
| --- | --- | --- |
| [旧帮助文章](https://gitee.com/help/articles/4136) | HTTP 200，但返回通用帮助中心内容，没有原 Pages 指南 | 不能沿旧教程完成现行部署 |
| [帮助中心搜索路径](https://help.gitee.com/search?q=pages) | HTTP 404，显示“找不到页面” | 此链接无效；单凭它不能证明产品下线 |
| 公开搜索 | 存在 2024 年以来称“维护、暂停或下线”的第三方讨论，也仍有近期发布的旧式教程 | 搜索发布日期不等于产品功能验证 |
| 正式公告、恢复通知、实际开通 | 本次未取得可复核的官方下线/恢复公告，也未登录账户测试开通 | 无法确定永久下线日期或账户差异 |

因此，实用回答是：**不要把 Gitee Pages 当成现在可直接使用的建站方案。** 这属于选型判断，并非已经证实“永久下线”。如一定要使用，需先通过当前控制台和客服确认，并实际测试首次发布、更新和对外访问。

## 可选方案比较

| 方案 | 大陆访问与备案 | 视频处理方式 | 费用、维护与建议 |
| --- | --- | --- | --- |
| 腾讯云 COS / 阿里云 OSS，中国内地地域 | 国内源站；自定义域名需备案，国内 CDN 也有备案要求 | 直接提供 MP4；需要时接 CDN | 存储、请求、流量按用量计费，无须维护操作系统；最适合本需求 |
| 国内轻量服务器 + Nginx/Caddy | 国内线路；正式网站域名需备案 | 可直接提供视频，但受套餐带宽限制；视频仍可交给对象存储/CDN | 有固定服务器费，需要更新、证书、备份等维护；有后端或偏好固定套餐时考虑 |
| 香港等境外服务器/对象存储 | 不接入大陆节点时一般无大陆 ICP 备案要求；仍跨境，不能保证速度 | 文件直出或接境外 CDN | 适合不想备案且能接受线路波动的情况；优先实测电信、联通、移动 |
| GitHub Pages / GitLab Pages | 海外托管；大陆不同地区、运营商体验可能不同 | 网页可引用外部视频；不推荐把视频库放进 Pages/Git | 文档发布省事；换成 GitLab 不代表解决跨境访问问题 |
| Cloudflare Pages | 免费全球网络不等于大陆节点服务；绑定自己的域名也不自动解决线路问题 | 单文件最大 25 MiB，较大视频需外部存储 | 适合试做或海外读者，不作为大陆稳定视频站的首选 |
| Vercel / Netlify 等海外平台 | 同样要承担跨境访问不确定性 | 视频宜外置 | 可列为部署便利型备选，本次未逐一验证套餐与访问质量 |
| CODING 历史静态托管 | 官方资料存在冲突 | 视频应外置 | 帮助页明确写“此服务已下线”，另有旧部署页和介绍页；暂不推荐作为新站依据 |

这里对大陆访问的判断基于部署位置、产品设计及官方说明，**未进行全国多运营商测速，也不构成任何服务的可用率承诺**。自定义域名解决入口和迁移问题；仅换域名不会把海外服务器变成国内服务器。

Cloudflare 官方 China Network FAQ 表示 Pages 在其大陆产品环境不可用，同时提到全球区域的 Pages 存在扩展进入大陆的可能；China Network 则是企业客户单独订阅、需 ICP 等条件的服务。这不能解读成“所有大陆用户永远打不开所有 Pages 网站”，也不能把免费 Pages 当作大陆 CDN。[6][7][8]

CODING 的[静态网站服务页](https://coding.net/help/docs/cd/static-website.html)直接显示“此服务已下线”，但[旧部署文档](https://coding.net/help/docs/pages/operating/deploy.html)和[腾讯云产品介绍](https://cloud.tencent.com/document/product/1726/96968)仍有相关描述。应优先以实际开通能力为准；它的[持续集成发布 COS 指南](https://coding.net/help/docs/ci/practice/static-website.html)可作为“构建后上传对象存储”的架构参考，不代表旧托管服务恢复。

## 视频怎么放

### 少量演示或课程：对象存储 + HTML5 播放器

网页和视频可以放同一个存储桶，也可以使用独立媒体域名。示例：

```html
<video controls playsinline preload="metadata" poster="/images/demo.jpg"
       style="max-width:100%">
  <source src="https://media.example.com/demo.mp4" type="video/mp4">
  当前浏览器不支持视频播放。
</video>
```

MP4 是容器，兼容性还取决于内部编码；一般可先使用 H.264 视频和 AAC 音频，并将 MP4 的索引信息前置（fast start）。测试时检查正确的 Content-Type、HTTPS，以及拖动进度时的 Range/206 响应。仅给文件改成 `.mp4` 后缀不能解决编码问题。

普通跨域 `<video src>` 播放不一定需要 CORS；使用 JavaScript 播放器加载 HLS 分片、读取视频到 canvas 或显式开启跨域请求时，按播放器要求配置 CORS。HLS 通常需要兼容播放器，不能假设所有浏览器都能原生播放 `.m3u8`。

### 视频成为主要内容：云点播

腾讯云点播等服务集成媒资管理、转码、自适应码流、分发播放和保护能力。网站前端仍可保持静态，播放器请求点播地址即可。是否使用云点播主要取决于所需能力，而不只是视频数量。[9][10]

需要收费课程、会员权限时，通常还要有后端或托管鉴权服务来校验身份并签发播放凭据；把固定密码或密钥写进静态 JavaScript 不能保护内容。防盗链也不等于防录屏。

### 全部公开视频：Bilibili 等平台嵌入

可把公开视频上传至平台，在站点嵌入其提供的播放器，减少自购视频流量。代价是播放样式、审核、登录提示、画质和平台规则由平台控制，需用实际视频验证手机和未登录访问体验。本次未完成特定视频的嵌入测试，故将其作为候选，不承诺所有视频均能无跳转完整播放。平台不是静态网站托管的替代品，也不要提取临时视频直链作为长期地址。

## 域名、备案与默认地址的实际限制

腾讯云 COS 官方指南支持静态网站，并明确：2024 年 1 月 1 日后创建的桶，使用默认域名（包括静态网站域名）访问文件不支持预览，建议配置自定义域名，源站类型选择静态网站源站。[1]

阿里云 OSS 官方指南同样支持静态网站，提示默认 Bucket 域名访问 HTML 会强制下载；正常浏览应绑定自定义域名，中国内地 Bucket 的域名需完成 ICP 备案。[2] 不能照旧教程假设“上传 index.html，直接分享默认桶地址”就能建站。

备案要求主要与是否接入中国内地服务器/CDN 有关，并不是所有自定义域名都必须备案。香港等境外部署一般不要求大陆 ICP 备案；接入大陆 CDN 后又需满足其要求。备案可接受主体、网站内容类型和接入条件需按选定服务商及所在地规定核对。购买存储桶也不自动等于取得首次备案所需的接入资格；已有备案或首次备案应分别确认。[3]

建议使用 `docs.example.com` 作为网站、`media.example.com` 作为视频入口，方便独立调整缓存或迁移。域名和 HTTPS 证书配置属于正式发布工作，CDN 可以按流量与分布逐步加入，不是静态网站能够运行的必要条件。

## 成本如何估算

本次不引用限时促销或未经核实的固定月价。文档站通常流量小，视频往往决定总费用。

- 直接对象存储：域名年费 + 存储容量 + 请求次数 + 公网下载流量；使用 CDN 后，再按 CDN 下行、回源及相应请求等项目计费。
- 云点播：视频存储 + 实际开启的转码/处理 + 播放下行加速流量；其他能力按需另计。[10]
- 服务器：实例套餐、流量/带宽、磁盘与维护时间；低价套餐的大磁盘不代表有足够播放带宽。

例如，一个 200 MB 视频被完整观看 1,000 次，理论下载量约 200 GB（按十进制计算，未计协议开销、重复请求和缓存行为）。CDN 缓存能减少源站回源，但不能免除用户播放的下行流量。4 Mbps 码率的 20 个并发观众，带宽需求约 80 Mbps，未计额外开销；5 Mbps 的轻量服务器带宽显然不足。

先估算视频总体积、每月实际观看次数和平均观看时长，再用服务商计算器报价；资源包不一定覆盖所有计费项。正式上线时设置预算提醒，特别关注视频被大量外链访问所产生的费用。

## 针对本需求的实施建议

1. 默认按“公开文档、少量视频、大陆读者、无需登录”开始。文档用 Markdown 编写，使用 VitePress 或 MkDocs 等生成静态文件；本次未对站点生成器做独立横评。
2. 选熟悉的腾讯云或阿里云，准备自有域名并核对备案接入条件，使用中国内地 COS/OSS 托管构建结果。无需另买服务器来运行这些 HTML 文件。
3. 视频先用对象存储的 H.264/AAC MP4；源码仓库只保存文档、配置、封面及视频地址，不把大视频反复提交进 Git。
4. 首次可手动构建上传，随后用 CI 自动构建、上传、刷新缓存。服务密钥放 CI 的密钥管理中，不能放进公开网页。
5. 有跨地域读者或视频访问量上升时接国内 CDN；需要转码、多清晰度或鉴权时改接云点播。
6. 发布验收至少覆盖首页、文档直达链接、中文路径、手机播放、拖动进度、HTTPS、404 与缓存更新，并请目标读者用实际运营商网络验证。

如果暂时不愿处理备案，先在海外 Pages 或香港部署最小站点，视频尽量使用合适的国内公开视频平台；接受访问波动后再决定是否长期使用。不要因为 Gitee 与 GitHub 的仓库访问体验不同，就推断所有海外/国内 Pages 服务具有相同差异。
