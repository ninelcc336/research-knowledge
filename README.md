## 归档约定

- 分类目录按调研内容动态生成，每篇调研只归入一个主分类，交叉领域使用标签表达。
- 文件名采用 `YYYY-MM-DD-主题.md`，日期取自正文明确记录的调研日期。
- 每篇调研使用统一的 YAML 元数据：`title`、`date`、`category` 和 `tags`。
- 索引按分类分组，组内按调研日期倒序排列；新增或移动调研后必须同步更新本页。
- Agent 的详细归档和内容保护规则见 [AGENTS.md](./AGENTS.md)。
