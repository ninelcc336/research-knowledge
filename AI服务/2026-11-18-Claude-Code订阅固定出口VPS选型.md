# Claude Code 订阅固定出口 VPS 选型

最近一次实质核查：**2026-11-18**。初次核查：2026-11-17。使用场景已由用户确认：**Claude Code 在本地运行，VPS 只作本人固定网络出口**。研究对象是官方 CLI 的本人订阅登录和使用，不是 API 中转、共享订阅或把订阅转换成 API 的服务。

本次更新：11 月 18 日直接读取 LisaHost 商品目录及相关分类，新增纽约和洛杉矶两款 ¥68 月付比较、常见术语解释及河南电信选型。用户进一步确认使用河南电信。本次仅更新 LisaHost 对比；DMIT、搬瓦工、社区反馈、Claude 官方规则和其他结论仍沿用 11 月 17 日核查，不表示已于 18 日全部复核。正文其余“当前”“本次”均按各段注明的原核查范围理解。

完成条件：核查近期订阅使用反馈、当前官网可见套餐及售后条件，给出可试用候选、配置要求和验证方法。本次没有购买 VPS、取得待分配 IP、登录 Claude 账户或进行跨日网络测试；结论是有证据支持的试用选择，不是实测封号率排名。

**如果从大陆家庭宽带直接连接这台出口 VPS，优先试洛杉矶 9929。** 原因是线路定位更匹配该场景：相同价格下，纽约给了更高的带宽与流量，洛杉矶强调大陆连接线路。50Mbps 在能够实际达到、且无明显丢包的前提下，通常足以供本人 Claude Code 交互使用；纽约 300Mbps 是服务器端口标称上限，不能理解为用户家中一定可跑满，或 Claude 回复速度会快六倍。

纽约地理位置一般意味着较长的中美路径，但具体延迟和晚高峰体验仍取决于路由和本地运营商，不能只凭城市断定实测差值。两款的 10GB/20GB 磁盘与 1000GB/3000GB 流量，对少量设备的纯文本编程交互通常都够；如还代理下载、浏览器、多模态或其他业务，应按实际用量判断。

**Claude 账号稳定性目前无法判定两款谁更好。** 两者虽有相同 IP 标签，实际 ASN、地址段、历史使用、地理识别与 Claude 接受情况仍需分配 IP 后确认；9929 是网络线路属性，不是住宅身份或较低封号率的证明。本次未取得两款同条件、近期订阅对照数据。

### 3.3 LisaHost 目录术语与河南电信的具体选择

**2026-11-18 核查。** 用户确认河南电信、本地运行 Claude Code，VPS 只作出口。以下解释用于识别不同商品维度；商家没有公开完整的 IP 分类判定方法，也没有提供本次可复核的河南电信测速。[O10]

#### 商品标签分别描述什么

| 标签 | 简单解释 | 不能据此认定的事项 |
| --- | --- | --- |
| VPS | 租用一台境外虚拟电脑，有自己的系统、分配的 CPU/内存/磁盘和网络，可安装出口软件 | 不是买完就自动拥有可连接的代理节点或 Claude 订阅，通常仍需自己配置 |
| KVM | VPS 使用的一种虚拟化技术 | 不表示独占整个物理机，也不表示住宅网络 |
| VDS | 常被商家用作另一类虚拟服务器的商品名称；LisaHost 多款 VDS 同样标 KVM | 仅凭名字不能推断独占 CPU、真实住宅托管、线路更好或比 VPS 更稳定，须看具体条款 |
| ISP | Internet Service Provider，即互联网服务提供商；在 IP 商品中常描述地址所属运营商或数据库分类 | 不代表一台机器直接放在家庭里 |
| 双 ISP | 非统一技术标准。住宅 IP 市场常用来指若干 IP 信息字段/库均呈现 ISP 或住宅属性；本站未说明其判定口径 | 不是两条家庭宽带、不是两个出口 IP、不是双线路自动容灾。单个商品明确仅配 1 IPv4 时，不能把“双 ISP”理解为送两 IP |
| 家宽／住宅 IP | 商家称出口地址具有面向家庭宽带用户的属性 | 可能是运营商地址租用/路由后的产品；仅凭标签不能确认真实民房、独享到何种程度或 Claude 的分类 |
| 原生 IP | 通常用来强调 IP 的注册、归属或地理识别与目标地区一致，市场口径不统一 | 不能保证所有地理数据库都一致，也不代表住宅、无历史或不封号 |
| 静态 IP | 一般指地址通常保持不变，具体取决于服务条款 | 不代表永久所有权、自动无风险；动态地址可改变，不符合本次优先固定出口的目的 |
| 三网大陆优化 | 商家针对中国电信、中国联通、中国移动连接大陆的路径作了优化 | 不是三个 IP，也不是三条独享宽带；不保证河南每个地区、去回程、全天均最佳 |
| 9929、4837、CN2 GIA | 线路名称：9929 通常指联通 AS9929，4837 指联通 AS4837，CN2 GIA 是电信的一类优质国际连接产品 | 不能理解为 9929 仅联通用户能用、或电信只能买 CN2；具体仍取决于去回程和互联路径 |
| BGP／国际线路 | BGP 是互联网路由协议，单独标注它不能说明大陆路径质量 | “国际 BGP、大带宽”不是“大陆优化”的同义词 |
| 双栈／双原生 | 本站德国相应产品描述为 IPv4 与 IPv6 两种协议 | 与“双 ISP”含义不同，IPv6 数量和配置方式应看商品说明 |
| 高防／50G 防御 | 指针对 DDoS 网络攻击的防护容量 | 与防止 Claude 封号或身份验证无关 |

可按这条路径理解：**河南电信本机 → 大陆到 VPS 的连接线路 → VPS 的境外出口 IP → Claude**。三网优化主要关系到前一段是否顺畅；住宅、原生、ISP 主要描述出口地址。两个维度可以组合，一种标签不能替代另一种。Claude 能否登录和持续使用还涉及平台及账户状态。

## 4. 你的场景该买什么配置

只承载本人少量设备的轻量出口时，可从 **1 核、1GB RAM、10—20GB 磁盘、单独 IPv4** 这一档开始。这是工程估计，不是 Claude 公布的出口服务器最低配置；吞吐需求和其他同时运行的软件会影响资源使用。

Claude Code 官方安装文档的 **4GB 以上 RAM** 要求针对运行 CLI 的设备。用户在本地运行时，不应直接把这个要求套到只转发连接的 VPS。[O6]

比内存更需要确认的是：

1. **大陆到 VPS 的路径**：在本人实际宽带、运营商和晚高峰下能否持续连接；CN2 GIA、9929、CMIN2 是线路属性，不能替代本地测试。
2. **实际出口地址**：独享实例不等于住宅 IP，分到一个 IPv4 也不等于商家保证永久不变；付款前确认续费后是否保持地址，以及被阻、更换或回收的条件。
3. **完整订阅链路**：浏览器授权、CLI 登录、正常请求和隔夜重启都能工作，而不是仅首页返回 200。
4. **可退出的付款周期**：先选月付或短周期，并读完整退款条件。先验证一个出口，再决定是否长期使用。

美国、日本、新加坡等属于当前官方支持地区，但香港不是；选择地区还要结合本人网络质量。这里没有证据证明“日本比美国更不容易封”或“贵线路比普通线路更不容易封”。[O7]

## 5. 本地 Claude Code 的接入与试用检查

官方当前支持 `HTTPS_PROXY`、`HTTP_PROXY`，**不直接支持 SOCKS 代理**。若出口软件只提供 SOCKS，本地还需要能供 CLI 使用的 HTTP 代理入口；不能只用 SSH 动态转发 `ssh -D` 后，就假定 Claude Code 可直接使用 `socks5://`。[O8]

独立 CLI 在 PowerShell 中的最小配置示意如下。`<本机HTTP代理端口>` 必须替换为已经运行的本地代理端口，字符串本身不能原样执行：

```powershell
$env:HTTPS_PROXY = 'http://127.0.0.1:<本机HTTP代理端口>'
claude
```

这只给当前终端启动的进程设置代理，不会自动配置浏览器。订阅授权使用的浏览器也应检查实际网络路径。官方规定环境变量读取优先顺序为 `https_proxy`、`HTTPS_PROXY`、`http_proxy`、`HTTP_PROXY`，已有小写变量可能覆盖上面的配置。Claude Desktop 管理连接的会话另有配置作用域，本示例针对独立 CLI。[O8]

拿到实际 VPS 后，在退款有效期内完成以下验证，才能判断是否适合自己的网络：

| 检查 | 应观察的结果 | 不能据此推导什么 |
| --- | --- | --- |
| 本地到 VPS 持续连接、晚高峰使用 | 有无连接中断、超时、明显丢包 | 单次低延迟不能代表全天稳定 |
| 浏览器正常打开 Claude 并完成本人订阅授权 | 授权全流程正常，不停在挑战或地区报错 | 网页可开不等于 CLI 可用 |
| CLI 确认订阅身份，做正常代码阅读/修改任务 | 使用订阅而非误走另一个 API Key，连续交互正常 | 一次响应不能证明续费或账号长期稳定 |
| 隔夜后重新启动 CLI、继续已有会话 | 正常恢复使用，记录完整报错与时间 | 无错误不能换算成统计意义的封号率 |
| 出现故障时分别检查 VPS 连通与 Claude 状态 | 区分网络超时、429/额度、授权失败和明确停用通知 | 不能把所有 API error 都叫作 IP 被封 |

仅请求 `api.anthropic.com` 或 `claude.ai` 首页，无法证明 OAuth、订阅身份及实际模型请求都成功。整个试用应使用本人官方客户端和正常使用负载，无需向 VPS 商家提供 Claude 密码或令牌。
