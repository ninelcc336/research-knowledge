# Cliproxy 代理 IP 产品与 Claude Code 适用性

调研日期：**2026-11-18**。研究对象为用户提供的 **https://cliproxy.com/**，核查产品类型、计费、交付方式、退款限制及与本人 VPS 固定出口场景的关系。已检索知识库，未找到同一网站的既有专题，因此独立成文。本次直接读取官网中英文首页、静态产品价格页、帮助文档和退款页；未注册、购买、测速、配置代理或验证 Claude 登录。

## 1. 结论

**Cliproxy 是代理 IP 服务商，提供现成的住宅／ISP 等代理出口。** 从本次读取的官网来看，它的主要产品不是可自行管理操作系统的 VPS，也不是 Claude 模型 API 中转或 Claude 订阅销售服务。[S1][S2][S4]

对用户“河南电信、本地 Claude Code、Clash Verge TUN、希望固定出口”的需求，概念上最接近的是 **Long-Term Static IP（长效静态 IP）**，而不是动态轮换或短效 IP。但**官网中英文页脚明确写着不支持在中国大陆使用**，因此不能将它推荐为已验证可直接替代 Evoxt／LisaHost 的大陆出口方案。[S1][S2]

中文原文：**“由于政策原因，本站代理服务不支持在中国大陆使用”**。英文对应：**“Due to policy reasons, this website's proxy service does not support use in mainland China.”** 网站未在本次读取页面进一步解释这句话指技术连接限制还是服务资格限制，不能自行缩小成“只是没有大陆 IP”。

本专题仅指该域名网站，不将同名或近名开源软件的能力、许可证或使用方式移植到这里。

## 2. 它卖的东西分别做什么

| 产品 | 交付与用途 | 当前官网宣传起价 | 对本次固定出口场景的意义 |
| --- | --- | --- | --- |
| 长效静态 IP | 租用长期保持的代理出口；网站称独享、无限流量，可用于社媒及电商 | 首页标 **$3/月起**；静态页提供 7、30、90 天周期，不同地区与类别有不同报价 | 产品形态最接近固定出口，但大陆使用限制、实际可达性、续费保留同一 IP 和 Claude 可用性未解决 |
| 短效住宅 IP | 按 IP 提取，用于短任务、地区测试等；首页称单个 IP 在线最长可达 6 小时 | **$0.04/IP 起** | 不适合作为长期不变的个人出口；购买额度有效期不能与单个 IP 在线时长混淆 |
| 动态住宅 IP | 按流量用代理池，支持轮换和粘性会话，用于采集、市场调研、地区访问测试 | 标准 **$0.72/GB 起**，企业 **$0.58/GB 起** | 粘性会话只是在一定会话期内尽量维持地址，不等于长期静态 IP |
| 动态不限量——端口 | 按端口和时长等计费，网站举例为问卷、文本下载 | **$0.38/天/端口起**，菜单称 3—30 分钟会话 | 更偏批量任务，不是为了单人 Claude Code 固定出口设计 |
| 动态不限量——带宽 | 根据带宽、时长等购买代理容量，面向大流量下载或采集 | **$38.33/天起** | 与本次轻量固定出口需求差距较大 |

以上是官网首页／导航的营销起价，**不是实际订单验证价，也不表示任一美国住宅 IP 均为 $3/月**。静态价格页区分“Residential Native”和“Home broadband broadcast”等类别，并列 US-Dual Comcast、United States、Japan、Germany 等；页面的多周期与地区组合需在实际选择后核价。本次没有登录确认库存、税费、最终可购总额或交付地区。[S1][S3]

网站另有 SERP API 入口，属于搜索结果相关服务的线索；本次未展开该产品，不把它解释为 Claude API。

网站所写“Data for AI／人工智能数据”，在首页上下文指数据采集、下载等用途，不能据此推导它提供 Claude 模型额度、订阅登录或官方授权。

## 3. 与 LisaHost／Evoxt 的区别

| 项目 | 用户目前的 VPS 方式 | Cliproxy 静态代理方式 |
| --- | --- | --- |
| 购买对象 | 一台有操作系统的虚拟服务器 | 一个由商家管理的代理服务入口及出口 IP |
| 谁安装出口软件 | 用户自己在 VPS 安装并维护 | 商家提供代理服务；用户配置连接参数 |
| 常见交付信息 | 服务器 IP、系统登录信息，之后自行生成节点配置 | 代理地址／端口、用户名与密码，或来源 IP 白名单 |
| 能否随意部署项目 | 可以在 VPS 资源和条款允许范围内部署 | 购买代理本身不等于获得服务器管理权限 |
| 网络表现 | 取决于 VPS 线路和所用协议 | 取决于代理入口、出口与完整连接路径，住宅标签不等于大陆线路优化 |

官网静态使用文档介绍：选择地区与使用期限、扣余额并取得 IP；使用列表显示用户名与密码，可续费，支持来源 IP 白名单模式。协议 FAQ 总体列出 HTTP、HTTPS、SOCKS5，静态教程展示 SOCKS5 测试示例；**不能据总体 FAQ 保证每个具体套餐都支持所有协议与功能**。[S5][S6]

从技术形态看，现成 HTTP／SOCKS5 代理通常可由支持这些协议的代理客户端配置，因此可能沿用“Clash Verge 接管本地流量”的思路。但它不一定提供与用户当前 VLESS／Trojan 等相同的节点链接，也未验证该商家代理在 Clash Verge TUN 下的 DNS、连接或可达性。本次不写未经测试的配置文件。

概念连接可表示为：`本地 Claude Code → 代理客户端 → 商家代理入口／出口 → Claude`。这只是说明交付层次，不是已经可用的大陆连接路径。官网明确不支持大陆使用，不能把“省去自己部署服务端”等同于“可以直连替代 VPS”。

## 4. 宣传和退款需要怎样理解

首页的“99% 成功率”“永不封锁”“更低封禁风险”等是商家宣传，未见本次可独立复核的 Claude Code 订阅成功率、河南电信表现或长期封号对照。**不能把代理请求成功率解释为 Claude 账号不封率**。[S1][S2]

退款页标注生效日 **2024-10-15**，但本次仍是官网提供的现行页面。正文有以下限制与表述：[S7]

- 订单确认、服务交付后，原则上不直接退款；对不可用或质量很差的代理，描述的补救方式包括返回账户余额。
- 又列明同一账户仅第一次可原支付渠道退款，其后退至站内余额；第一次原路退款仍可能扣费用：支付宝 3%、银行卡 5%，最低 $0.5；USDT 固定 $2。
- 已开始发送或接收数据被视为使用，条款写明不退款；违规、冻结等也有不退款情况。

条款中的“交付后不直接退款”、首次原路退款及不可用 IP 补救之间没有在本次阅读中形成清晰、无条件的试用流程。因此**不应承诺“付费测试 Claude 不行就一定退钱”**。退款条款提及支付宝等渠道，也不能替代当前具体订单付款渠道的实际验证。

## 5. 对用户当前选择的建议

若目的是继续使用本人 Claude 订阅、维持已有 Clash Verge TUN 工作流，**本次不足以支持因为 Cliproxy 页面价格更低就放弃已研究的 VPS 方案**。两者售卖对象不同；该站又明确限制大陆使用，且没有验证其入口是否能从河南电信稳定连接。

仅从产品理解上，用户应区分“自己管理一台出口服务器”和“租商家现成的代理出口”。若以后研究住宅代理，最接近当前目标的方向是长期静态、可续费保留地址的产品；动态轮换、按提取次数售卖的短效产品与保持同一出口的目标不符。当前不推荐具体购买 Cliproxy 套餐。

VPS 候选和相关 IP 标签解释见[Claude Code 订阅固定出口 VPS 选型](./2026-11-18-Claude-Code订阅固定出口VPS选型.md)。本专题未重新核查 Anthropic 规则，也不以更换代理豁免主报告中的实际所在地要求。
